\# NovaTech Landing Page



\## Project Description



NovaTech is a simple and responsive landing page for an AI-powered productivity platform. The page is designed to present the platform, highlight its features, and provide contact information.



\## Technologies Used



\- HTML5

\- CSS3



\## Features



\- Sticky navigation bar

\- Hero section with call-to-action button

\- Features section with three feature cards

\- Contact information

\- Social media placeholders

\- Responsive design for mobile devices

\- Smooth scrolling navigation
